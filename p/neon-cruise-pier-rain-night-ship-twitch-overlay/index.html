About this product

Description

Cruise pier rain night — neon coast stream layout

A tropical-neon stream layout for "Cruise Pier Rain Night", with a rainy night mood, a cruise pier and a ship in the rain at night, and a plus-sign texture. Bright blue frames (#2870ff) sit against gold name strips (#ffdc32). Title and names use Poiret One Regular; handles and subtitles use Syne Regular. Original illustrated art made for gamers, just-chatting and podcast streams, IRL or creative work, and screen-share tutorials.

Works with

OBS Studio (scene collection import). Use it while streaming to the usual streaming platforms.

How it works

  1. Buy the pack and get the ZIP from your order page
  2. Unzip into a folder (the import expects paths like C:/OBS Layouts/320-cruise-pier-rain-night/; if files show as missing, use Missing Files → Search Directory)
  3. In OBS choose Scene Collection > Import, pick the 1080p or 4K JSON, then assign your cameras, game or screen capture and alerts. The README walks through the steps.

Please note

  • This is an instant digital file. Nothing physical is shipped.
  • Sources are unlocked so you can rearrange the layout to fit your stream.
  • Preview images may show placeholder webcam or game content for display only.
  • Colors can look slightly different on different screens.
