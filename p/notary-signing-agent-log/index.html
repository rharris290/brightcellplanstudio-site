About this product

Description

Notary Signing Agent Log from BrightCellPlanners: a hyperlinked undated digital planner for iPad and tablets. For notaries public and loan signing agents: commission details, notarial act entries (signer, ID, act type, fee), a loan signing tracker with scanbacks and return shipping, a loan package checklist, signing service contacts, invoices and mileage. It also includes a phone edition with tall pages for iPhone and Android phones, for use in GoodNotes or Notability.

Features

  • Side tabs on every page: jump anywhere in one tap
  • The tab for the page you are on is highlighted
  • PDF bookmarks (outline) for quick navigation
  • Next and back buttons on multi-page sections
  • Undated: start any day and reuse it
  • Decorative art: embossed gold notary seal, kept soft behind writing areas
  • Roomy writing lines, tick boxes and boxes sized for handwriting
  • Landscape iPad size (2388 x 1668 px)
  • Works with GoodNotes, Notability, Noteshelf, Xodo and other PDF annotation apps

Write on it anywhere

  • Every page is writable: open the PDF in GoodNotes, Notability, Noteshelf, Samsung Notes, Xodo or another PDF note app and write with an Apple Pencil, any stylus or your finger.
  • Works on iPad, Android tablets, iPhone and Android phones. You can also type text boxes and add stickers.
  • Tabs and links keep working while you write (in GoodNotes, switch to read-only mode to tap links, then back to write).
  • On a phone the screen is small, so zooming in or using a stylus makes handwriting easiest.
  • A note-taking app is needed to write on the pages. A basic PDF viewer will only show them.

How to use

  1. Open your Etsy purchase and save the files (unzip the ZIPs).
  2. Import it into your note-taking app.
  3. Tap the tabs and tiles to move around. Tip: in GoodNotes, use read-only mode to tap links, then switch back to write.
  4. Duplicate any page you need more of.
