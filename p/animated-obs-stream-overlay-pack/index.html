  • 10 animated scenes in BOTH 16:9 (1920×1080) and 9:16 (1080×1920): Starting Soon, Be Right Back, Just Chatting, Stream Ended, Intermission, Technical Difficulties, Offline, Instant Replay, plus text-free backgrounds. Each one comes as WebM, PNG and a text-free version.
  • Live Gameplay and Fullscreen Cam layouts in the OBS scene collections
  • 6 animated alerts (Follow, Subscriber, Tip, Bits, Raid, Gift Sub): transparent WebM, text-free WebM, PNG still and a green-screen MP4 fallback
  • 6 original alert sounds synced to the animations (normalised to about −14 LUFS), plus a quieter soft set, in WAV, MP3 and OGG
  • Webcam frames (standard, alt colour, circle, large, small), chat frame (+ text-free), replay frame and a gameplay overlay
  • 2-second stinger transition in both formats, plus a fade-only low-motion version
  • Editable HTML browser sources for alerts, labels, scene titles with countdown, chat, goal bar and captions. You change the text in the URL, so no image editing is needed.
  • StreamElements custom widgets: alerts, chat, goal bar and event ticker
  • Streamlabs custom CSS for the Alert Box and Chat Box, plus an 8-step manual setup guide
  • 4 OBS Studio scene collections (Windows and Mac × horizontal and vertical)
  • 9 Twitch panels (About Me, Schedule, Socials, Rules, Discord, Tip Jar, Donate, Merch, blank), safe-zone guides and a PDF setup guide
  • Fonts under the free SIL Open Font License

▶ EVERY BOX IS MOVABLE In the OBS scene collections every box is its own unlocked source or group: cam frames, chat frame + chat, scene title panels, the gameplay bottom bar, replay frame, Now Playing label, goal bar, caption box and alerts. Drag and resize any of them without breaking the artwork. Each cam frame already has a Webcam source fitted inside it: double-click Webcam, pick your camera, then click the cam group to drag or resize it. The original all-in-one backgrounds are still included as optional extras.

▶ ACCESSIBLE BY DESIGN

  • WCAG AA (4.5:1) text contrast
  • Colour-blind-safe accents and a unique icon for each alert type
  • OpenDyslexic / Atkinson Hyperlegible font toggle for the browser sources
  • No-flash / reduced-motion mode, plus a full low-motion set (still scenes, fade-only alerts and stinger)
  • A caption slot in the gameplay and chatting layouts
  • Soft alert sound set

▶ COMPATIBILITY (please read)

  • OBS Studio (Windows and Mac): import the included scene-collection JSON. The setup guide covers where to unzip the folder so the file paths match.
  • Streamlabs Desktop: MANUAL setup. There is NO one-click Streamlabs import file. The included step-by-step guide walks you through adding each scene as a Media Source, setting up the Alert Box for each alert type with its WebM and sound, and setting up the vertical canvas / Dual Output. It takes about 15 minutes.
  • StreamElements: paste the included custom widget code (HTML/CSS/JS/fields) into a custom widget.
  • Other software that supports browser or media sources can use the WebM, PNG and HTML files directly.

You need your own streaming software and accounts. The promo images show "YOUR GAMEPLAY HERE" placeholders, and no game footage is included.
