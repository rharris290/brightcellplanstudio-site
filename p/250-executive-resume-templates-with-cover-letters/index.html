How to edit

  • Microsoft Word: unzip the file, open the .docx and click any text to type over it. Change colors with Shape Fill and Font Color.
  • Google Docs: upload the .docx to Google Drive, then right-click > Open with > Google Docs. Save it as a PDF when finished.
  • Delete or copy sections to fit your experience. Save as PDF before you send it.
  • No photo is used, so the layouts stay clean and ATS-friendly. If you want to add a photo in Word: Insert > Pictures, then Picture Format > Crop > Crop to Shape > Oval for a round photo.
