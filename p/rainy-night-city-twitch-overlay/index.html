About this product

Description

Rainstatic crossing — stream layout

A stream layout for "Rainstatic Crossing", with rain-slick yellow-lamp crossing scenes, wet asphalt, streetlamp glow, CRT static and fog. Yellow frames (#ffe000) sit against steel-gray name strips (#9ab0c0). Title and names use Big Shoulders Display Bold; handles and subtitles use Rubik Regular. Original illustrated art made for gamers, just-chatting and podcast streams, IRL or creative work, and screen-share tutorials.

Works with

OBS Studio (scene collection import). Use it while streaming to the usual streaming platforms.

How it works

  1. Buy the pack and get the files from your order page
  2. Unzip every ZIP into C:/OBS Layouts/ (the main pack fills C:/OBS Layouts/rainstatic-crossing/; the extras ZIP fills a folder beside it. If files show as missing, use Missing Files → Search Directory)
  3. In OBS choose Scene Collection > Import, pick the 1080p or 4K JSON, then assign your cameras, game or screen capture and alerts. The README walks through the steps.

Please note

  • This is an instant digital file. Nothing physical is shipped.
  • Sources are unlocked so you can rearrange the layout to fit your stream.
  • Preview images may show placeholder webcam or game content for display only.
  • Colors can look slightly different on different screens.
